# Dataset

## Source

- **Dataset name:** DVS Benchmark 2021 – Ballistic Dataset  
- **Paper:** Holešovský, O., Škoviera, R., Hlaváč, V., Vítek, R. (2021). *Experimental Comparison between Event and Global Shutter Cameras*. Sensors, 21(4), 1137.  
- **Official repository:** [holesond/dvs-benchmark-2021](https://github.com/holesond/dvs-benchmark-2021)  
- **File used in this experiment:** `ballistic.hdf5`  
- **SHA256:** `c6f9bc5bd5f808a70776127f110a9544ce32bc18b8ca5e5a6c`  
- **Approximate size:** 512 MiB  

The file is hosted externally (Google Drive / original CIIRC CVUT mirror) and is **not** versioned inside this repository due to size constraints.

## HDF5 Structure (relevant subset)

```
ballistic
├── calibration
│   ├── atis/image_sequence
│   └── photron/image_sequence
├── 7.62x51mm
│   └── <shot_id>
│       ├── photron
│       │   ├── image_sequence   # uint8 [N, H, W]
│       │   └── params
│       └── atis
│           ├── events           # int32 [N_e, 4] → (t, x, y, polarity)
│           └── params
├── 9x19mm_low_charge
│   └── ...
└── 9x19mm_standard_charge
    └── ...
```

**Important:** The official HDF5 does **not** contain bounding-box annotations, labels, or any object-detection ground truth.

## Other available shots (not used)

From the dataset audit performed during the experiment:

- `7.62x51mm`: 4 shots  
- `9x19mm_low_charge`: 5 shots  
- `9x19mm_standard_charge`: 2 shots  
- `calibration`: 2 groups  

Only shot `7.62x51mm/0` was extracted and used for the current PoC.

## Calibration parameters

Present under `ballistic/calibration/{atis,photron}`:

- `camera_matrix` (3×3)
- `radial_distortion`
- `tangential_distortion`
- `rotation` (3×3)
- `translation` (1×3)
- `world_units`

These parameters were **not** used for the YOLO training or the 2D image-space Kalman filter in the current experiment.

## Ground-truth status

> The official DVS Benchmark 2021 ballistic HDF5 does **not** provide bounding-box ground truth for object detection.  
> All detection labels used in this PoC are **pseudo-labels** generated by classical computer-vision techniques (see [pseudo_labeling.md](pseudo_labeling.md)).

# YOLO Training

## Model

- Architecture: **YOLOv8n** (Ultralytics)
- Pretrained weights: `yolov8n.pt` (official COCO checkpoint)
- Single class: `projetil` (class id 0)

## Training configuration (as executed)

```python
model = YOLO("yolov8n.pt")
results = model.train(
    data=str(YAML_PATH),   # dataset.yaml
    epochs=15,
    imgsz=640,
    project=...,
    name="yolo_ballistic_poc",
    exist_ok=True,
    verbose=False
)
```

| Hyperparameter | Value |
|----------------|-------|
| Epochs | 15 |
| Image size | 640 |
| Batch size | default (Ultralytics auto) |
| Optimizer | auto |
| Train set | `images/train` (130 frames) |
| Validation set | `images/train` (**same set**) |

## Critical experimental limitation

> **Validation used the same image set as training.**  
> Therefore the reported metrics do **not** represent independent generalization performance.

All frames belong to a single continuous high-speed shot. Temporal correlation between consecutive frames is extremely high.

## Output artifacts produced

- `models/yolo_ballistic_poc/weights/best.pt` (~6.2 MB)
- `models/yolo_ballistic_poc/weights/last.pt` (~6.2 MB)
- `results.csv`
- `args.yaml`
- Training curves and confusion matrices (see [evaluation.md](evaluation.md))

The file `models/best.pt` present at the root of the `models/` directory in this repository is a copy of the `best.pt` produced by the run above.

## Training data origin

The 130 images and the 83 positive labels were generated by the pseudo-labeling pipeline described in [pseudo_labeling.md](pseudo_labeling.md).  
No official ground-truth bounding boxes from the HDF5 were used.

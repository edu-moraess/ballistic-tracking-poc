# Pseudo-Labeling

## Critical statement

The bounding-box annotations used to train the YOLOv8n model in this PoC are **not** official ground truth from the DVS Benchmark 2021 dataset.

They are **pseudo-labels** generated by a classical computer-vision pipeline (background subtraction + contour detection) inside the experiment notebook.

The official HDF5 file contains **no** `bounding_boxes`, `labels`, or object-detection annotations.

## Generation method

Implemented in the experiment notebook (auto-labeling cell).

### Algorithm summary

1. Load `frame_000.png` as the static background.
2. For every subsequent frame:
   - Compute absolute difference with the background.
   - Threshold at value **30**.
   - Find external contours.
   - Select the largest contour whose area is **> 5 px²**.
   - Compute the centroid of that contour via image moments.
   - Place a **fixed-size 20 × 20 pixel** bounding box centered on the centroid.
3. Write a YOLO-format label file:
   - Positive detection → `0 cx cy w h` (normalized)
   - No valid contour → empty `.txt` file (negative sample)

### Exact parameters used

| Parameter | Value |
|-----------|-------|
| Background frame | `frame_000.png` |
| Difference threshold | 30 |
| Contour selection | largest contour |
| Minimum contour area | > 5 px² |
| Bounding-box size | **fixed 20 × 20 pixels** |
| Class ID | 0 (`projetil`) |
| Coordinate format | YOLO normalized (`cx cy w h`) |

### Code fragment (as executed)

```python
background = cv2.imread(..., cv2.IMREAD_GRAYSCALE)  # frame_000
box_size = 20
w_norm = box_size / w
h_norm = box_size / h

diff = cv2.absdiff(background, img)
_, thresh = cv2.threshold(diff, 30, 255, cv2.THRESH_BINARY)
contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

if contours:

    if cv2.contourArea(largest) > 5:
        M = cv2.moments(largest)
        cx = int(M['m10'] / M['m00'])
        cy = int(M['m01'] / M['m00'])
```

These numbers were recorded in the notebook output at the time of label generation and were confirmed by the Ultralytics training log (`Instances = 83`).

## Limitations of the pseudo-labels

- Bounding-box size is artificial (fixed 20×20), not derived from the true object extent.
- Detection depends on a static background assumption and a fixed threshold.
- Sensitive to illumination changes, residual motion blur, and noise.
- No temporal consistency or multi-object association was enforced.
- Not validated against any external or manual ground truth.

## Relationship to official dataset

The DVS Benchmark 2021 ballistic data provides high-speed frames and event streams. It does **not** provide object-detection bounding boxes. Any detection labels used in this repository are an experimental construct of the PoC and must not be treated as official annotations.

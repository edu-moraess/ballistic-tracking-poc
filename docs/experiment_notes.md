# Experiment Notes

## What was actually executed

This repository captures a **proof-of-concept (PoC)** that combines:

1. High-speed Photron frames from the DVS Benchmark 2021 ballistic dataset.
2. Pseudo-labels generated by classical background subtraction + contour detection.
3. Fine-tuning of YOLOv8n on those pseudo-labels.
4. A simple OpenCV Kalman filter that produces a 2D image-space trajectory.

## Key factual statements

- The official HDF5 **does not** contain bounding-box ground truth.
- All detection labels used for training are **pseudo-labels**.
- Bounding boxes were forced to a fixed size of **20 × 20 pixels**.
- Exactly **83** frames received a positive pseudo-label; **47** frames were treated as negatives.
- Training and validation used the **identical** set of 130 frames.
- The resulting metrics therefore **cannot** be interpreted as measures of generalization.
- The trajectory produced by the pipeline is a **2D image-space trajectory**, not a 3D ballistic trajectory.

## Notebook of record

The full experimental procedure (extraction, pseudo-labeling, training, tracking video generation) was executed inside the Colab notebook:

**`Yolotrain.ipynb`**

(located in the associated Google Drive workspace; not versioned in this repository).

Relevant cell sequence observed:

```
Dataset inspection / structure print
        ↓
Frame extraction (130 PNGs)
        ↓
Classical detection + Kalman (background subtraction)
        ↓
Pseudo-label generation (auto-labeling cell)
        ↓
dataset.yaml creation + YOLOv8n training (15 epochs)
        ↓
Tracking video generation (best.pt + Kalman)
        ↓
Artifact packaging / GitHub push helpers
```

## Artifacts retained

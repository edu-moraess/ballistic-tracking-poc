# Ballistic Trajectory Tracking PoC

Proof-of-concept pipeline that combines:

- High-speed frames from the **DVS Benchmark 2021** ballistic dataset (Photron camera)
- **Pseudo-labels** generated by classical background subtraction + contour detection
- Fine-tuned **YOLOv8n** detector
- OpenCV **Kalman filter** producing a **2D image-space trajectory**
- Experimental evaluation of detection agreement, state estimation, and one-step-ahead prediction

> This is an experimental PoC. It is **not** a production ballistic measurement system.

---

## Project idea

The project explores the interaction between **Computer Vision and State Estimation**:

```text
Photron frames
      ↓
Classical Computer Vision
      ↓
Pseudo-labels
      ↓
YOLOv8n
      ↓
Measurement (x, y)
      ↓
Kalman Filter
      ↓
State Estimation [x, y, vx, vy]
      ↓
One-step Prediction
```

The central experimental framing is:

**Measurement → State Estimation → Dynamics → Prediction**

The current implementation operates entirely in image coordinates. It does not reconstruct a metric 3D trajectory.

---

## Important scientific caveats

Please read these points before interpreting any result:

1. **No official ground-truth bounding boxes**  
   The DVS Benchmark 2021 HDF5 does not contain object-detection annotations. All labels used for training were generated automatically (pseudo-labels).

2. **Pseudo-label method**  
   - Background = `frame_000.png`
   - Threshold = 30
   - Largest contour with area > 5 px²
   - Centroid of the contour
   - **Fixed-size 20 × 20 pixel** bounding box
   - Result: 83 positive frames, 47 negative frames (out of 130)

3. **Train / validation leakage**  
   Both `train` and `val` pointed to the same folder (`images/train`).  
   **The original training metrics do not represent independent generalization performance.**

4. **Evaluation reference**  
   The classical CV measurements are also the source of the pseudo-label signal used during YOLO training. Therefore, YOLO and Kalman errors reported in the audits measure **agreement with the classical CV reference**, not independent ground-truth accuracy.

5. **Trajectory type**  
   The output is a **2D image-space trajectory** (pixel coordinates). It is not a 3D metric ballistic trajectory.

6. **Velocity interpretation**  
   Kalman velocity is expressed in **pixels per frame**. It should not be interpreted as physical projectile velocity.

Full documentation of the experiment lives under [`docs/`](docs/).

## Experimental results

The archived YOLO model was trained for 15 epochs using YOLOv8n on the pseudo-labeled sequence. The original training run reported:

| Training metric | Result |
|-----------------|-------:|
| Precision | 0.9273 |
| Recall | 0.9218 |
| mAP@50 | 0.9765 |
| mAP@50–95 | 0.7616 |

**Important:** these values come from a validation split that pointed to the same images used for training. They are therefore retained as historical training metrics, not as evidence of independent model generalization.

### Post-training audits

A separate read-only audit was performed on the 130-frame sequence:

| Audit | Result |
|-------|--------:|
| CV-positive frames | 83 / 130 |
| YOLO detections at conf ≥ 0.25 | 71 / 130 |
| YOLO × CV median center error | **0.334 px** |
| Kalman × CV median error | **0.315 px** |
| One-step Kalman prediction × CV median error | **0.365 px** |
| CV-positive / YOLO standard-threshold misses | 12 |
| Low-confidence YOLO recoveries | **12 / 12** |

The 12 standard-threshold misses were all recovered when the YOLO confidence threshold was lowered for diagnostic analysis. This indicates that they were low-confidence responses rather than complete absence of model response.

The gated Kalman experiment showed rapid convergence after initialization. Its largest errors occurred mainly during periods where YOLO did not provide a valid measurement and the filter continued in prediction-only mode.

The one-step-ahead audit measured a median prediction displacement of approximately **0.37 px relative to the classical CV reference**. This should be interpreted as short-horizon consistency with the reference signal, not independent predictive accuracy.

For the complete audit protocol, intermediate results, and methodological limitations, see [`docs/evaluation.md`](docs/evaluation.md).

## Quick start (tracking only)

The repository ships the trained weights and a ready-to-run tracking script.

```bash
git clone https://github.com/edu-moraess/ballistic-tracking-poc.git
cd ballistic-tracking-poc
pip install -r requirements.txt

# Requires a folder of extracted Photron frames (see docs/data_pipeline.md)
python src/tracking_pipeline.py
```

The script loads `models/best.pt`, runs detection + Kalman filtering, and writes a visualization video.

## Training (for reference)

The original training that produced `models/best.pt` was performed in a Colab notebook using the pseudo-labels described above.

The script `src/train_yolo.py` is a simplified extraction/training helper; it assumes a different HDF5 layout than the one that was actually used and should be treated as legacy scaffolding.

See [docs/yolo_training.md](docs/yolo_training.md) and [docs/reproducibility.md](docs/reproducibility.md) for the precise protocol that generated the archived weights.
